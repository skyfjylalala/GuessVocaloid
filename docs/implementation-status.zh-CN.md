# 第一版实现记录

日期：2026-10-18。分支：`dev`。初版已由用户部署到 Cloudflare；本次加入难度等级及 GitHub 自动部署配置。

## 已实现

- 新应用在 `web/`，旧 Demo 原样保留。
- React + Vite + TypeScript；Cloudflare Worker API + 本地 D1。
- 真实离线快照按原投稿百万再生筛选，导入 1,000 首。原始大文件仅本地缓存，忽略提交。
- 原投稿匹配，剔除翻唱和通用 TTS，常见声库版本合并为角色；保留作曲、编曲及调声作者。
- 无限练习、八次机会、集合部分匹配和数字方向、BPM 区间及未知字段。
- 初级 Top 50、中级 Top 200、高级 Top 1,000；答案、搜索、曲库浏览和成绩统计跟随难度。旧千首进度兼容为高级。
- 中／日／英界面，歌曲及别名／作者搜索，浏览曲库，刷新恢复，揭晓、原投稿链接、无剧透成绩复制和浏览器统计。
- 加密会话；答案留在后端，输入、重复猜测和局状态验证。
- 相同判题与数据接口同时提供 Worker/D1 和 Node/SQLite 入口；SQL 导出恢复脚本和部署步骤已附上。

## 验证证据

- 自动化测试：13 项通过，覆盖规则、搜索、会话、请求边界、真实曲库 SQLite、数据清洗、难度池边界及旧会话兼容。
- 生产构建：TypeScript 检查、Worker 和 React 构建通过。
- `wrangler deploy --dry-run` 和远程发布成功，静态资源与 Worker 分目录，数据库和资源绑定可识别。
- 本地 Worker/D1 及独立 Node/SQLite 的首页和健康接口均返回 HTTP 200。
- 本地 D1 实际导出 SQL，恢复至独立 SQLite 文件，验证保留 1,000 首歌曲。
- 浏览器实际操作：中文别名「千本樱」找到日文歌曲，键盘选择、提交比较、刷新后保留记录、揭晓、复制成功反馈、中日英切换、窄屏曲库弹窗。
- 难度交互实测：默认初级 50 首，切换中级 200 首，已有猜测时切换需要确认，刷新保留难度。
- GitHub Secret 和账号 ID Variable 已配置；[首次真实 Actions 运行](https://github.com/skyfjylalala/GuessVocaloid/actions/runs/39101668866) 的测试、构建、D1 migrations 和 Cloudflare 发布全部通过。后续推送 `dev` 的应用变更会自动部署。
- 自动部署后线上健康接口返回 1,000 首；初级、中级、高级新局均返回 HTTP 200，题池分别为 50、200、1,000，进行中的答案不随响应返回。

## 已知范围

- 数据采用第三方旧快照；再生数不实时。最新缺失字段统计见 `web/data/import-report.json`。缺失 BPM 显示未知。
- 常见声库归并规则独立维护；新声库和长尾数据仍可能需要调整。
- 目前没有每日模式、账号、排行榜或多人对战。浏览器数据清除后，个人进度和统计会丢失。
- 加密会话可防止直接读出答案和修改当前令牌，但不是竞技防作弊系统。
- Cloudflare 账号、真实 D1 ID 和生产会话密钥已由用户配置。迁移到 PostgreSQL 仍需适配 SQL、数据类型和驱动，并非原 SQL 直接导入。
